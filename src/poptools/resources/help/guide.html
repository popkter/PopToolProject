02 /

把第一段脚本放进来

  1. 打开「自定义」→「新建脚本」

    填写名称和说明，选择图标及脚本类型。下方模板均标注了对应类型。

  2. 粘贴模板，保存脚本

    用占位符标记每次运行需要修改的值，工具箱会自动生成参数控件。

  3. 填参数，选设备

    在右侧「参数配置」填写内容。涉及 Android 时，先开启 USB 调试并授权，再选择「目标设备」。

  4. 点击「运行脚本」，查看输出

    文本框旁的保存图标可将当前输入设为默认值；下次选择脚本或重启应用后仍然保留。

脚本类型要与内容一致。 Windows 运行 Bash 需要可用的 Bash 环境，如 Git Bash；Windows 内置终端首次使用时按提示准备 PowerShell 7，macOS 使用系统 Shell。
03 /

一段占位符，就是一个控件

参数在执行前替换成文本。无需用 input() 或 Read-Host 等待输入。

自由输入文本框
${标题}

例如 ${包名}，每次运行前输入内容。

带默认值可修改
${标题:默认值}

例如 ${数量:3}。默认值用冒号分隔，数值类型需要脚本自行转换。

固定选项下拉框
${触摸点显示:开启=1|关闭=0}

左侧是显示文字，右侧是实际值；用竖线分隔选项，第一项为默认选项。

选择已有文件文件选择器
${APK安装包@file:C:\Downloads\example.apk}

也可写为 ${APK安装包@file}。点击按钮选文件，或直接修改路径。

选择文件夹文件夹选择器
${日志目录@dir:C:\Logs}

也可写为 ${日志目录@dir}。支持直接输入或拖入文件夹路径。

声明一次，多处复用Var 声明
Var level = ${日志级别:信息=I|警告=W|错误=E}
adb logcat "*:${level}"

Var 放在脚本开头，正文通过内部名称引用；声明行会在执行前移除，不是脚本语言本身的语法。

试一试 · 参数如何变成命令仅展示替换结果，不执行命令

输入或粘贴完整模板，下面会自动生成参数。支持文本、默认值、下拉选项、@file、@dir 和 Var 声明；也兼容旧版 pVal 声明与等号默认值语法。

参数预览
替换后实际执行的脚本
引号需要自己写。 工具箱不会自动添加引号或转义特殊字符；含空格的路径应按脚本语言加引号。参数名使用中文、字母、数字或下划线；占位符定义不能包含花括号或换行。不可信输入不能仅靠引号保证安全。

复制一份，开始使用

复制完整内容到新建脚本的编辑器，并选择对应的脚本类型。

显示 Android 触摸点 PowerShell

生成一个开关选项下拉框。需要已连接并授权的 Android 设备。

POWERSHELL / 01
adb shell settings put system show_touches ${触摸点显示:开启=1|关闭=0}
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

查看日志目录 PowerShell

生成文件夹选择器；用 Var 让路径在检查和列出文件时复用。无需 Android 设备。

POWERSHELL / 02
Var logs = ${日志目录@dir}

$ErrorActionPreference = "Stop"
if (-not (Test-Path -LiteralPath "${logs}" -PathType Container)) {
    Write-Error "请选择有效的日志目录"
    exit 1
}
Get-ChildItem -LiteralPath "${logs}" -File |
    Select-Object Name, Length, LastWriteTime

按数量输出序号 Python

生成数量输入框，默认 3；演示显式转换和范围校验，仅使用 Python 标准库。

PYTHON / 03
import sys

try:
    count = int("${数量:3}")
except ValueError:
    sys.exit("数量必须是整数")

if not 1 <= count <= 100:
    sys.exit("请输入 1 到 100 之间的数量")

for number in range(1, count + 1):
    print(f"第 {number} 项")

模板按普通受信任输入编写。路径示例不要输入双引号、换行或 PowerShell 表达式；Python 数量框仅填写整数。校验发生在文本替换之后，不能代替转义。

05 /

运行前后，这些很实用

如何保存默认值？

在文本参数框中输入内容，点击右侧「设为默认值」保存图标。文件和文件夹参数的保存按钮在选择按钮左侧。空输入也可保存以清空默认值；运行期间不可保存，下拉框和开关不使用此按钮。

ADB 命令会在哪台设备上运行？

应用通常自动检测脚本中的 ADB 调用。动态拼接识别不到时，在编辑器将「Android 设备」设为「使用」。界面通过 ANDROID_SERIAL 指定设备；脚本中显式使用 adb -s、-d、-e 或 -t 时，以脚本为准。已选设备断开不会自动改用其他设备。

如何分享和迁移脚本？

单个脚本：详情区点击「分享」，接收方用「自定义 → 导入」读取剪贴板。批量迁移：使用「设置 → 脚本目录 → 导出脚本 / 导入脚本」。导入前自动备份，同路径文件使用导入版本，其他本地脚本保留；外观、设备记录和推送方案不随脚本迁移。

Python 缺依赖或脚本未停止怎么办？

通过 Python Doctor 检查并安装依赖，或在内置终端使用 pip install。脚本可在详情区停止；同一个脚本不能重复启动。关闭主窗口只是隐藏到托盘，需要完全退出时使用托盘菜单的「退出」。
